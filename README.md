# A/B Test: Landing Page Conversion Analysis

## Business Problem

A company is testing a new landing page to determine whether it improves user conversion compared with the existing version.

The key business question is:

> **Does the new landing page generate a statistically significant increase in conversion rate?**

The analysis focuses not only on the overall A/B test result, but also on whether the observed effect remains consistent across key user segments.

---

## Objective

The objectives of this analysis are to:

* Compare conversion rates between the control and treatment groups.
* Measure the relative and absolute uplift generated by the new landing page.
* Determine whether the difference is statistically significant.
* Evaluate whether the treatment effect is consistent across age, gender, and device segments.
* Translate statistical results into a business recommendation.

---

## Hypotheses

### Primary hypothesis

**H₀ (Null Hypothesis):**
There is no difference in conversion rate between the control and treatment groups.

**H₁ (Alternative Hypothesis):**
The conversion rate differs between the control and treatment groups.

A significance level of **α = 0.05** was used.

---

## Dataset

The dataset contains **294,478 users** divided into two experimental groups:

| Group     |   Users |
| --------- | ------: |
| Control   | 146,926 |
| Treatment | 147,552 |

Available variables include:

* User ID
* Experiment group
* Landing page
* Conversion status
* Age
* Gender
* Location
* Session duration
* Pages visited
* Device type
* Purchase amount

---

## Key Metrics

### Conversion Rate

Conversion rate measures the proportion of users who completed the target action.

**Conversion Rate = Conversions / Total Users**

### Absolute Uplift

The difference in conversion rate between treatment and control.

**Treatment CR − Control CR**

### Relative Uplift

The percentage improvement relative to the control group.

**(Treatment CR − Control CR) / Control CR**

### Statistical Significance

A two-proportion **z-test** was used to determine whether the difference in conversion rates is statistically significant.

---

## Methodology

The analysis was performed using Python and included:

1. Data loading and validation.
2. Exploratory data analysis.
3. Conversion rate calculation.
4. Control vs. treatment comparison.
5. Two-proportion z-test.
6. Segment analysis by:

   * Gender
   * Device type
7. Visualization of experiment results.

---

## Statistical Testing

A two-proportion z-test was performed using `statsmodels`.

The test compares the conversion proportions of the two experimental groups.

### Results

**Z-statistic:** -46.28

**p-value:** < 0.001

Since the p-value is significantly below the 0.05 significance threshold, the null hypothesis is rejected.

### Interpretation

The observed difference in conversion rates between the control and treatment groups is **statistically significant**.

The treatment version demonstrates a substantially higher conversion rate than the control version.

---

## A/B Test Results

| Metric          | Control | Treatment |
| --------------- | ------: | --------: |
| Users           | 146,926 |   147,552 |
| Conversion Rate |  11.87% |    17.95% |
| Absolute Uplift |       — |  +6.08 pp |
| Relative Uplift |       — |    +51.2% |

The treatment group increased conversion by approximately **6.08 percentage points**, corresponding to a relative uplift of approximately **51%** compared with the control group.

---

## Segment Analysis

To assess whether the treatment effect was consistent across different user groups, conversion rates were analyzed by age, gender, and device type.

### Age

The treatment group demonstrated higher conversion rates across all analyzed age groups.

| Age Group | Control | Treatment |
| --------- | ------: | --------: |
| 18–25     |  12.09% |    17.98% |
| 25–35     |  12.01% |    18.06% |
| 35–45     |  11.49% |    17.79% |
| 45–65     |  11.84% |    17.50% |

The positive treatment effect was observed consistently across age segments.

### Gender

| Gender | Control | Treatment |
| ------ | ------: | --------: |
| Female |  11.83% |    17.84% |
| Male   |  11.89% |    18.06% |
| Other  |  12.66% |    17.89% |

The treatment group maintained a higher conversion rate across all gender segments.

### Device

| Device  | Control | Treatment |
| ------- | ------: | --------: |
| Desktop |  11.95% |    18.08% |
| Mobile  |  11.74% |    17.71% |
| Tablet  |  11.85% |    18.01% |

The treatment effect was also observed across desktop, mobile, and tablet users.

---

## Business Recommendation

The statistical test provides strong evidence that the treatment landing page performs better than the control version.

Based on the observed **51% relative conversion uplift** and statistically significant test result, the treatment version should be considered for rollout.

Before a full production rollout, additional checks could include:

* Experiment duration and potential time effects.
* Business impact on revenue and purchase value.
* Long-term user behavior.
* Monitoring conversion after deployment.
* Additional experimentation to identify which landing-page changes drive the improvement.
